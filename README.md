# Enchanted Royal Hotel — milestone download

This branch contains the complete front exterior, entrance and grand foyer delivery bundle, plus previews rendered from its real Blender geometry.

Download **EnchantedRoyalHotel_FrontSlice_Milestone1.zip** using GitHub’s **Download raw file** button on that file’s page. Extract it on your Mac, then read README.md and docs/MAC_IMPORT.md. The ZIP includes Blender, FBX and GLB assets, textures, collision geometry, integration helpers, source generators and the unchanged original Stage 3.1 input files.

Original gameplay scripts and Royal Egg price (750 diamonds) remain unchanged. Offline tests pass; Roblox Studio import, gameplay and cloud persistence require verification.
